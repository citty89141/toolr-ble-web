ENDEX CAN 橋接器 — 韌體更新與燈號手冊

給燒錄／現場維護人員的操作指南：如何用瀏覽器對裝置進行 BLE 無線韌體更新（OTA）、如何從裝置燈號判斷目前狀態，以及更新失敗時的處理方式。

裝置代號 ENDEX_CAN_XXYY（開機自動產生，XXYY 依每台裝置不同） 目標晶片 ESP32-H2 瀏覽器 Chrome / Edge（電腦或 Android）
⬆ 開啟韌體更新頁面 先看更新步驟 燈號對照
01 · 系統一覽

這台裝置在做什麼

ENDEX CAN 橋接器夾在「手機／電腦」與「車輛 CAN 匯流排」之間，同時也會主動去連線車上的踏頻功率感測器。更新韌體時，實際走的是最左邊這條 BLE 路徑。

手機 / 電腦瀏覽器
ble_ota.html · Web Bluetooth
BLE
ENDEX CAN 橋接器
ESP32-H2
CAN
車輛控制器
驅動器 / 電池 / 儀表
亦以 BLE 主動連線車上踏頻／功率感測器
韌體更新全程只透過 BLE 無線 進行，不需要拆開裝置或接電腦排線 — 除非是全新、從未燒錄過的裝置（見「首次燒錄」章節）。
02 · 狀態確認

燈號對照表

裝置上的指示燈預設為「自動模式」，用閃爍快慢反映目前的 BLE 連線狀態 — 更新前後都可以先看燈號確認裝置活著、且處於預期狀態。

快閃
週期約 125 ms
尚未連線，裝置正在廣播、等待配對。開始 OTA 前應該看到這個狀態。
慢閃
週期約 500 ms
已與手機／電腦建立 BLE 連線。傳輸韌體期間應維持這個狀態。
常滅
手動關閉
由主控 App 送出燈號指令強制關閉，不影響 BLE／CAN 功能。
常亮
手動開啟
由主控 App 送出燈號指令強制恆亮，同樣不影響連線狀態判讀。

常滅／常亮是可被手機主控 App 手動覆蓋的模式，OTA 更新頁面本身不會去改燈號 — 如果更新前燈號不是快閃或慢閃，通常代表有人手動切換過，不影響更新，但無法單靠燈號判斷連線狀態，可直接進行下一步嘗試連線。

03 · 主要流程

BLE 無線更新（OTA）

使用瀏覽器版更新頁面，全程六個步驟，最後會自動驗證新韌體是否開機成功。更新頁面會在新分頁開啟，可以一邊對照本手冊操作。

⬆ 開啟韌體更新頁面
瀏覽器需求：必須使用電腦或 Android 手機上的 Chrome 或 Edge（需支援 Web Bluetooth）。iPhone Safari 不支援，請改用「備援工具」章節的方式。
1

準備韌體檔案

取得工程師提供、經過驗證的 .bin 韌體檔（例如 gattc_gatts_coex.bin）。

請確認檔案來源與版本正確 — 頁面本身不會檢查這份 .bin 是不是「對的那一份」。

2

開啟更新頁面並選檔

開啟 韌體更新頁面，在「① 選擇韌體檔案」點一下選檔，或直接把 .bin 拖曳進虛線框。

選好後會顯示檔名與大小，「② 確認版本」左側會立刻顯示這份 .bin 內嵌的版本號（不需連線裝置）。若顯示「無法辨識」，代表檔案不是正確的韌體，更新按鈕會維持停用。

3

選擇裝置、確認版本（建議）

按「🔍 連線讀取裝置版本」，瀏覽器會跳出裝置清單，選取名稱開頭為 ENDEX_CAN_ 的裝置後按「配對」。頁面會顯示裝置目前版本，並自動比對：

✔ 檔案版本較新正常情況，可以更新
＝ 與裝置完全相同不需要更新；硬要更新時頁面會再確認一次
⚠ 檔案版本比裝置舊會降版，按更新時頁面會跳出確認

這一步只讀取、不寫入。選過的裝置在按「開始 OTA 更新」時會直接沿用，不必再選一次。附近有多台裝置時，請對照實體序號（貼在裝置上或由工程師告知），避免選錯台。跳過這一步也可以，按更新時才會跳出裝置清單。

4

開始更新，等待傳輸完成

按「⬆ 開始 OTA 更新」。上方的「連線 → 開始 → 傳輸 → 驗證」會顯示目前階段，進度條下方會顯示已傳送大小、傳輸速度與預估剩餘秒數。過程中裝置燈號應保持「慢閃」。

更新期間頁面會盡量防止螢幕休眠，誤按關閉分頁也會先跳出提醒。仍請讓手機／電腦靠近裝置、不要切換到省電模式，以免藍牙連線中斷。

5

裝置自動重新開機

傳輸完成後頁面會自動送出結束指令，裝置隨即重開機套用新韌體，約需數秒鐘。

6

自動驗證結果

頁面會倒數 8 秒等裝置開機，再自動重新連線（最多 8 次），最後在進度條下方顯示結果卡片，並把「裝置目前」版本更新成實際運行的版本：

✔ 更新成功 — 新韌體驗證通過並正常運行，卡片會顯示新版本號，可以結束頁面。
⚠ 新韌體未通過驗證 / 無法確認更新結果 — 請見下方「疑難排解」，先不要重複燒錄同一份檔案。

需要回報工程師時，展開頁面最下方的「詳細記錄」，截圖或複製內容一起附上。

04 · 備援方式

瀏覽器無法使用時

若手邊只有不支援 Web Bluetooth 的裝置（例如 iPhone），可改用命令列版工具，流程與網頁版一致，一樣會自動驗證。

命令列工具

ble_ota_tester.py，需要 Windows/Mac 電腦裝好 Python。

1pip install bleak
2python ble_ota_tester.py firmware.bin
獨立執行檔

不想裝 Python 時，工程師可事先把上述工具打包成單一 ble_ota_tester.exe（PyInstaller），直接雙擊執行、拖入或帶入韌體路徑即可，其餘步驟相同。

05 · 特殊情況

首次燒錄（全新／裸機裝置）

從未燒錄過韌體的全新板子，還沒有 BLE OTA 服務可用，必須先用 USB 排線接上電腦，用燒錄工具寫入一次完整韌體。之後才能改用上面的無線 OTA 流程更新。

檔案燒錄位址備註
bootloader.bin0x0000ESP32-H2 開機程式，位址是 0，不是常見的 0x1000
partition-table.bin0x8000分割表
ota_data_initial.bin0x10000OTA 狀態區，缺這個之後無法用無線更新
gattc_gatts_coex.bin0x20000應用程式本體
簡易燒錄工具（推薦）

將上表四個 .bin 檔與 flash_first_time.bat 放在同一個資料夾，雙擊執行、輸入連接埠（如 COM5）並確認，會自動依上表位址燒錄四個檔案，不需要手動輸入指令。

需求：電腦已安裝 Python 並可執行 esptool.py。

手動指令

燒錄指令範例（COMx 換成實際連接埠）：

esptool.py --chip esp32h2 -p COMx -b 460800 write_flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 ota_data_initial.bin 0x20000 gattc_gatts_coex.bin
06 · 疑難排解

更新失敗時怎麼辦

頁面顯示「此瀏覽器不支援 Web Bluetooth」，按鈕無法按
使用了 Safari、Firefox，或 iPhone 上的任何瀏覽器
改用電腦或 Android 手機上的 Chrome / Edge；只有 iPhone 時請改用「備援工具」。
顯示「未選擇裝置」
裝置清單跳出後按了取消，或清單裡沒有任何 ENDEX_CAN_ 裝置可選
重新按一次按鈕並選取裝置；若清單是空的，請看下一項。
掃描不到 ENDEX_CAN_ 開頭的裝置
裝置未通電、不在藍牙範圍內，或已被其他手機／電腦占用連線中
確認裝置電源與燈號（應為快閃／未連線狀態）；若燈號是慢閃，代表已有其他裝置連著，請先讓那邊斷線再試。
傳輸到一半突然中斷、進度條卡住
藍牙訊號不穩、裝置離太遠，或手機進入省電/鎖螢幕模式打斷了連線
讓裝置與手機保持近距離、關閉省電模式，重新整理頁面後從頭再做一次即可，不會因此把裝置變磚（新韌體要驗證通過才會生效）。
重連後顯示「未驗證」或 8 次都連線失敗
新韌體開機自我檢查沒通過，系統已自動退回原本可用的舊版本
不要重複燒錄同一份 .bin。先確認燈號是否恢復快閃（代表裝置仍正常運作於舊韌體），並回報工程師這份韌體檔案與序號，待確認後再重新嘗試。
更新顯示成功，但不確定裝到的是哪個版本
結果卡片沒有顯示版本，或「裝置目前」顯示「舊版韌體（無版本資訊）」
網頁版會在結果卡片與「裝置目前」欄位顯示實際運行的版本；若沒顯示，代表裝置上跑的是更早、還沒有 0xFE04 版本特徵值的舊韌體（不影響本次更新是否成功），可直接以提供的 .bin 檔名／交付紀錄核對版本。
07 · 附錄

技術參考

給工程師 / 進階排錯用，一般更新流程不需要用到以下內容。

OTA 服務特徵值（0xFE00）
名稱UUID方向用途
Ctrl0xFE01手機 → 裝置0x01=開始, 0x02=結束
Data0xFE02手機 → 裝置韌體資料塊，每塊最多 512 bytes
Status0xFE03裝置 → 手機0x00=閒置, 0x01=驗證通過並運行中
Version0xFE04裝置 → 手機（讀取）組成 "版本 日期 時間" 字串，例如 1.0.0 Mar 30 2025 17:22:33

「版本」來自專案根目錄的 version.txt（純文字檔，工程師每次發版手動更新），build 時會自動內嵌進韌體；「日期／時間」是編譯當下的時間戳，由 build 系統自動填入，可用來確認是不是最新那次 build。這個值跟 ble_ota.html「更新檔案版本」本機解析 .bin 顯示的內容是同一個來源，兩邊必定一致。

Web Bluetooth 掃描過濾條件

更新頁面以裝置名稱前綴 namePrefix: 'ENDEX_CAN_' 過濾掃描結果；裝置名稱在每次開機時，由藍牙 MAC 位址末兩碼動態組成（例如 ENDEX_CAN_A1B2），並非固定字串。

適用 ENDEX CAN 橋接器（ESP32-H2）。韌體檔案、命令列工具與協定技術細節請洽負責工程師。
